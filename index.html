      Where this comes from

      The catalogue is built by listing the two public archives directly: the HPRC bucket on AWS (s3://human-pangenomics) and the HGSVC2 and HGSVC3 folders on the 1000 Genomes / IGSR FTP site. For methylation, the start of the read files was opened to check whether the calls are inside. Data from other projects (1000 Genomes, MAGE, Geuvadis, ENCODE) is matched by cell-line ID.

      Good to know

      • Methylation is usually inside the read files. You rarely need a separate download: modern PacBio and Nanopore BAM files already carry the 5mC calls. A donor without the mark may still have it in files that were not checked.
      • HGSVC2 and HGSVC3 are one cohort. Every HGSVC2 donor is also in HGSVC3, so they are shown together as HGSVC.
      • “Recorded but not public”. For a few HGSVC donors the consortium's own sheet lists data that is not on the public archive. The donor's page says so.
      • Other projects used the same cell lines, not the same cells. MAGE, Geuvadis and ENCODE grew their own cultures. Same genome, different experiment.
      • Seven donors are in both cohorts and are counted once in totals.
      • Some files have no donor name (pooled runs). They are kept in _unattributed.json.
